## Master style block (paste into every prompt)

```
STYLE: Ultra-premium dark editorial tech visual. Near-black background #0a0a0c with a
subtle #16161b surface plane. Single accent: acid lime #c9f24d, used sparingly (5–10%
of frame) as light, edge-glow or a single element. Off-white #f2f1ec for structure lines.
No other hues. Thin 1px hairline geometry at 9–16% white opacity. Soft volumetric haze,
gentle film grain, shallow depth of field. Studio product-shot lighting, one key light
from upper-left, cool rim light. Abstract and architectural — no faces, no text, no logos,
no UI screenshots, no stock-photo people. Centred composition with generous negative space.
Rendered like Octane / Blender cycles, 8k, physically based materials: matte anodised
aluminium, smoked glass, brushed graphite.
FORMAT: 16:9, cinematic.
NEGATIVE: text, letters, watermark, logo, people, hands, faces, clutter, rainbow colours,
blue tech cliché, neon cyberpunk, lens flare spam, low contrast mush.
```

For each block below: use the master style + the STEP line. For **video**, append the MOTION
line. For **GIF**, use the shorter MOTION (LOOP) line — a tight 2–3s seamless loop, no easing
holds, safe to compress.

## Practical notes

- **Aspect ratios**: 16:9 for the hero and journey-step visuals, 1:1 for the mobile
  `svc__m-visual` crops, 21:9 if used in a wide engagement-row banner.
- **Poster + video pairing**: `ServiceHeroVisual` and `ServiceVisual` (`src/components/pages/ServiceVisual.tsx`)
  currently render as CSS/SVG. Treat these prompts as upgrades — export a static poster (first
  video frame) for the CSS fallback and `prefers-reduced-motion`, and the looped MP4/WebM for
  motion-enabled viewports.
- **Video length**: 6–8s for the two `svc__visual` panels (desktop pinned aside + mobile), muted
  autoplay, seamless loop, export MP4 (H.264) + WebM.
- **GIF use case**: reserve GIFs for the compact `svc__step` nav rail or small thumbnail contexts
  where a video element is overkill — keep under ~400KB, 2–3s loop, no audio track needed anyway.
- **Consistency trick**: generate Hero first, then use it as the style/image reference for 01–07
  and the engagement-models visual so material and lighting stay identical across the set.
- **Accent discipline**: same rule as the process set — if lime exceeds ~10% of frame, regenerate.
